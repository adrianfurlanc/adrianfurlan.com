# Spanish blog posts

Put the Spanish version of a post here with the **same filename** as the English
post in `../blog/`: `meet-adrian.md` here translates `../blog/meet-adrian.md`.

The front matter needs only `title`, `excerpt` and `caption`. There is no `date`:
the English post's date is used, so the two can never disagree. Leave `image`
out to reuse the English photo, or add `image: ./photo.jpg` for a different one.

The Spanish blog lists every English post; where a file exists here it is shown
instead, otherwise the English text appears with a "not translated yet" note.

Files whose name starts with `_` (like this one) are not posts.
